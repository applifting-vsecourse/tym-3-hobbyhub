# ADR-0011: Identita uživatele a autentizační služba

**Status:** Navrženo ❓ <br>
**Datum:** 11-10-2026 <br>
**Rozhodující:** Marek

## Kontext

Z feature breakdownu v0.4:

- Registrace, přihlášení, obnova a změna hesla jdou přes hotové autentizační řešení (F-03.1, F-03.4, F-03.5, F-13.6). Google login je Nice to have (F-03.6).
- Povinné je jen „jméno / přezdívka“, pohlaví a celé datum narození (F-03.1).
- Evidují se verze právních dokumentů a souhlas při registraci (F-01.2).
- Lokalitu uživatel zadává dobrovolně; souhlasy s automatickou geolokací jsou odložené (F-04.7).
- Onboarding lze dokončit, nebo přeskočit (F-04.8).
- UI je jen v češtině, angličtina je odložená (F-12.7).

Model měl `passwordHash`, `googleId`, `firstName`, `lastName`, `nickname`, `locationConsentAt` a odvozený `/displayName`.

## Rozhodnutí

```
User
- authId: String                       // identifikátor u autentizační služby
- displayName: String                  // jméno / přezdívka, jedno pole
- termsAcceptedAt: DateTime
- termsVersion: String
- onboardingCompletedAt: DateTime [0..1]   // dokončeno i přeskočeno
- preferredLanguage: Language          // Nice to have
```

- Mažou se `passwordHash`, `googleId`, `firstName`, `lastName`, `nickname`, `locationConsentAt` a omezení na ně navázaná.
- Hesla, Google účty, MFA správců i ověřovací tokeny drží autentizační služba, ne doménový model.

## Zvažované možnosti

- **A: Hesla a externí účty v doménovém modelu**
  - Výhody: vše na jednom místě.
  - Nevýhody: v0.4 chce hotovou službu; citlivá data, která aplikace nepotřebuje.
- **B: Jen odkaz na účet v autentizační službě (zvoleno)**
  - Výhody: méně citlivých dat (F-12.4); přidání Google loginu nemění model.
  - Nevýhody: model závisí na tom, že služba vrací stabilní identifikátor.

Pro jméno: **A** jméno, příjmení a přezdívka (v0.2) proti **B** jedno pole `displayName` (zvoleno, F-03.1 v0.4).

## Důsledky

- Organizátor vidí u schválených účastníků e-mail a `displayName` (F-04.2), jiné jméno neexistuje.
- Ověření e-mailu se dál ukládá v `emailVerifiedAt` (F-03.2, F-11.2).
